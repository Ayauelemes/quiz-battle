 Brain Battle - Quiz Game Application
Brain Battle — бұл пайдаланушылардың білімін сынауға арналған интерактивті Quiz (сұрақ-жауап) платформасы. Жоба заманауи технологиялар арқылы жасалған және рөлдік басқару жүйесімен (Admin, Moderator, Player) жабдықталған.

- Frontend:React.js, React Router DOM
- Backend:Node.js, Express.js
- Мәліметтер базасы: PostgreSQL
- Дизайн: CSS3 

Негізгі мүмкіндіктер

- Рөлдік жүйе: `Admin`: Пайдаланушыларды және барлық сұрақтарды басқарады.
  - `Player`: Ойын ойнайды, статистикасын көреді және пікір қалдырады.
- REST API: Толыққанды CRUD (Create, Read, Update, Delete) операциялары.
- Ойын логикасы:Сұрақтарға жауап беру, уақытты бақылау және нәтижені автоматты есептеу.
- Хабарламалар жүйесі: Ойыншылар мен админ арасындағы ішкі хабарламалар (Inbox).
- Қауіпсіздік: Environment variables (`.env`) қолдану және рөлдерді сервер деңгейінде тексеру.
